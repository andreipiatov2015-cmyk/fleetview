# FleetView — управление компьютерами с мастер-компьютера

Мастер-консоль (GUI) + агенты на управляемых Windows-ПК в локальной сети.

| Требование | Как реализовано |
|---|---|
| 1. Экран «как в AnyDesk» с запущенными ПК | Карточки онлайн-машин (имя, пользователь, IP, ОС). Агент шлёт heartbeat каждые 10 с; машину, которая молчит 30 с, консоль убирает из списка |
| 2. Одинаковые команды: на одной, выбранных или всех | Галочки на карточках + кнопки «На выбранных» / «На всех». PowerShell или CMD. Команды выполняются параллельно, вывод и код возврата показываются по каждому ПК |
| 3. Удалённый рабочий стол | Кнопка «Рабочий стол»: если за ПК работает человек — теневой сеанс (вы видите и управляете его экраном, не выкидывая), если никого нет — обычный вход. Адрес берётся живой, не зависит от смены IP |
| 4. Доступ только для Администратора | Вход в консоль проверяет пароль через `LogonUser` и членство в группе «Администраторы» (BUILTIN\Administrators, работает с любым языком Windows). Агент запускается как задача планировщика под учётной записью Администратора с наивысшими правами |

## Файлы

```
console.py         мастер-консоль (GUI, PySide6)
netcore.py         сетевой сервер мастера
agent.py           агент для управляемых ПК
protocol.py        общий протокол (TCP + JSON)
winutil.py         Windows-функции: админ, DPAPI, RDP, теневой сеанс, сессии
version.py         номер версии и адрес репозитория
updater.py         проверка и установка обновлений с GitHub
build_agent.bat    сборка FleetViewAgent.exe на мастере
install_agent.bat  установка агента на ПК (запускать от имени администратора)
start_console.bat  запуск консоли
```

## Установка

### 1. Мастер-компьютер
1. Установите Python 3.10+ с python.org (при установке отметьте «Add python.exe to PATH»).
2. Запустите `start_console.bat` — при первом запуске поставится PySide6.
3. При первом запуске появится окно настройки: введите логин и пароль
   локального Администратора и скопируйте **токен**: он понадобится агентам.
4. Разрешите входящие подключения на порт 7420 (PowerShell от имени администратора):
   ```powershell
   New-NetFirewallRule -DisplayName "FleetView" -Direction Inbound -Protocol TCP -LocalPort 7420 -Action Allow
   ```

### 2. Собрать агента (один раз, на мастере)
Запустите `build_agent.bat` на **мастер-компьютере**. Он соберёт `FleetViewAgent.exe`
и откроет папку `agent_package` (в ней `FleetViewAgent.exe` + `install_agent.bat`).
**Python на компьютерах пользователей не нужен.**

> Антивирус (в том числе Защитник Windows) иногда принимает exe, собранные PyInstaller, за подозрительные.
> Если exe удаляется, добавьте папку `C:\FleetView` в исключения.

### 3. Каждый компьютер пользователя
1. Скопируйте папку `agent_package` на компьютер, например в `C:\FleetView`
   (если копируете архивом, сначала **распакуйте** его).
2. Щёлкните `install_agent.bat` **правой кнопкой → «Запуск от имени администратора»**.
3. Ответьте на вопросы: IP мастера, порт (7420), токен. Агент **сразу проверит связь**
   с мастером и скажет, что не так (неверный IP, закрытый порт, неверный токен).
4. На вопрос об автозапуске ответьте Enter (да), затем подтвердите имя администратора
   (определяется автоматически) и введите его пароль.

Агент создаёт задачу планировщика `FleetViewAgent` (при старте Windows, под Администратором,
наивысшие права), сразу её запускает и включает входящий RDP. Через несколько секунд ПК
появится в консоли.

> Без вопросов (массовое развёртывание):
> `FleetViewAgent.exe --master 192.168.1.10 --port 7420 --token ТОКЕН --install`

### Если ПК не появился в консоли
* Посмотрите журнал `C:\FleetView\agent.log`: там есть причина.
* Проверьте задачу: `schtasks /Query /TN FleetViewAgent`, запустить вручную можно так: `schtasks /Run /TN FleetViewAgent`.
* Самая частая причина: на мастере не открыт порт 7420 в брандмауэре (см. шаг 1.4).

## Важно знать

* **RDP есть только в Windows Pro / Enterprise.** В Home-версии входящий RDP недоступен, и кнопка «Рабочий стол» на таких ПК работать не будет (команды работают).
* **Пароль Администратора должен совпадать на мастере и на всех ПК.** Консоль подключается по RDP как `ИМЯ_ПК\<администратор>` с паролем, введённым при входе в консоль. Если пароли разные, Windows попросит ввести пароль в окне RDP.
* Пароль нигде не сохраняется на диск. Токен в конфиге консоли (`%APPDATA%\FleetView\console.json`) зашифрован DPAPI.
* Имя учётной записи вводите так, как оно называется в системе: в русской Windows встроенная учётка называется «Администратор».
* Лимит на одну команду — 300 с (`COMMAND_TIMEOUT` в `agent.py`). Интерактивные команды, которые ждут ввода, не поддерживаются.

## Что нового в версии 1.1

**Не зависит от смены IP.** Машины опознаются по постоянному ID, а не по адресу.
Агент сам переподключается к мастеру и сообщает текущий адрес; подключение к
рабочему столу всегда идёт на актуальный адрес.

**Подключение, не выкидывая пользователя (теневой сеанс).** Если за компьютером
работает человек, кнопка «Рабочий стол» открывает *теневой сеанс*: вы видите тот
же экран и можете управлять, а пользователь остаётся в системе. Если за ПК никого
нет — выполняется обычный вход на рабочий стол. Это штатная возможность Windows;
агент включает её при установке (политика Shadow = 2 и правила брандмауэра).

> Теневой сеанс — общий экран: пользователь видит, что вы делаете. Это осознанный
> выбор; «невидимое» подключение на клиентской Windows штатно невозможно.

## Обновления (через GitHub)

Репозиторий: https://github.com/andreipiatov2015-cmyk/fleetview (публичный).

* **Агенты** раз в 30 минут проверяют последний релиз и, если он новее, молча
  скачивают новый `FleetViewAgent.exe`, заменяют себя и перезапускаются.
* **Мастер** проверяет обновления при запуске и по кнопке «Проверить обновления».
  Если версия новее — показывает описание и спрашивает, обновляться ли сейчас.

### Как выпустить новую версию
1. Поднимите номер в `version.py` (например, `1.1.0` → `1.1.1`).
2. Запустите `publish_release.bat` на мастере (нужен установленный Git и
   привязанный репозиторий).
3. GitHub Actions на бесплатном Windows-раннере сам соберёт `FleetViewAgent.exe`,
   упакует консоль и опубликует релиз. Через несколько минут агенты начнут
   обновляться автоматически, а в консоли появится предложение обновиться.

Токен GitHub при этом в программу **не зашивается** и никуда не передаётся:
скачивание из публичного репозитория не требует авторизации, а сборку релиза
Actions делает своим встроенным токеном.

## Безопасность: что стоит доделать перед боевой эксплуатацией

Текущая версия рассчитана на доверенную локальную сеть:
* **Трафик не шифруется.** Токен и вывод команд идут по сети открытым текстом. Следующий шаг — обернуть сокеты в TLS (`ssl` из стандартной библиотеки, самоподписанный сертификат мастера, отпечаток которого прописан в агентах).
* **Агент не проверяет подлинность мастера.** Тот, кто сможет выдать себя за IP мастера, сможет отправлять команды. Это закрывает тот же TLS с привязкой к сертификату.
* Конфиг агента `agent_config.json` с токеном лучше держать в папке, доступной только администраторам (например, `C:\FleetView` с урезанными правами NTFS).

## Проверено

* Сетевое ядро + агенты на loopback: регистрация 3 агентов, отказ при неверном токене, команды на всех и на выбранных, кириллица в выводе, коды ошибок и stderr, параллельное выполнение, автоматическое переподключение после обрыва.
* GUI в offscreen-режиме: карточки, выбор, запуск команды, вывод по каждому ПК.
* Windows-части (LogonUser, проверка группы, DPAPI, schtasks, mstsc) написаны через ctypes и стандартные утилиты, но на реальной Windows ещё не запускались. Первый прогон стоит сделать на 2–3 машинах.
